# Sistema-de-Cadastro-de-Pratos
//Sistema web em PHP e MySQL para cadastro e geranciamento de pratos e colaboradores.

## Instrucoes de Uso (XAMPP)

1 Copie a pasta dC:\xampp\hto projeto para docs\.
2 Inicie os servicos Apache e MySQL no XAMPP Control Panel.
3 Acesse http://localhost/phpmyadmin, crie o banco 'restaurante' e importe a tabela 'prato'.
4 Acesse a aplicacao no navegador: http://localhost/Sistema-de-Cadastro-de-Pratos/index.php.
